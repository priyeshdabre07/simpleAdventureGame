# Mosslight

A small, choose-your-own-adventure game set in a moonlit forest. Explore the
woods, find useful items, and decide what becomes of the moon bell.

## Play

Open `index.html` in a modern web browser. No build step, package installation,
or server is required.

## How to play

- Choose an action to move through the story.
- Collect items to unlock some choices.
- Keep an eye on your warmth; risky actions can lead to an early ending.
- Reach the moon bell for one of several possible endings.
- Use **Start over** at the top of the page to begin a fresh story.

The game works on desktop and mobile. The scene illustrations are made with CSS;
the page loads its DM Sans and Playfair Display fonts from Google Fonts, with
system font fallbacks if they are unavailable.

## Project files

- `index.html` — page structure and game interface
- `styles.css` — visual design, responsive layout, and scene artwork
- `game.js` — story scenes, choices, inventory, warmth, and endings
